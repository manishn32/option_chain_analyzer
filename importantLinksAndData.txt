FYERS SDK CURRENT VERSION : 2.1.0


Install Fyers into .m2 using below command.
PS C:\Users\SESA796586\Downloads\analyser\optionsAnalyser> mvn install:install-file `
>> -Dfile="C:\Users\SESA796586\Downloads\analyser\optionsAnalyser\fyersjavasdk-1.0.jar" `
>> -DgroupId=com.tts.in `
>> -DartifactId=fyersjavasdk `
>> -Dversion=1.0 `
>> -Dpackaging=jar

Dependency to Add in POM AFTER INSTALLING

<dependency>
    <groupId>com</groupId>
    <artifactId>fyersjavasdk</artifactId>
    <version>1</version>
</dependency>


ALSO ADD org.JSON DEPENDENCY FOR FYERS

<dependency>
    <groupId>org.json</groupId>
    <artifactId>json</artifactId>
    <version>20211205</version>
</dependency>


Run mvn clean compile
