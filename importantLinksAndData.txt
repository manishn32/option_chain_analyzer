FYERS GIT HUB REPO : https://github.com/FyersDev/fyers-java-sdk.git

FYERS SDK CURRENT VERSION : 2.1.0


Install Fyers into .m2 using below command in terminal.
mvn org.apache.maven.plugins:maven-install-plugin:3.1.4:install-file `
-Dfile="D:\OptionAnalyzerApplication\option_chain_analyzer\fyersjavasdk-1.0.jar" `
-DgroupId=com `
-DartifactId=fyersjavasdk `
-Dversion=1 `
-Dpackaging=jar `
-DgeneratePom=true

Dependency to Add in POM AFTER INSTALLING

<dependency>
    <groupId>com</groupId>
    <artifactId>fyersjavasdk</artifactId>
    <version>1</version>
</dependency>


ALSO ADD org.JSON DEPENDENCY FOR FYERS

<dependency>
    <groupId>org.json</groupId>
    <artifactId>json</artifactId>
    <version>20211205</version>
</dependency>


Run mvn clean compile
